# 🔐 User Authentication System

### A modern, responsive login and registration interface built with HTML, CSS, and JavaScript.

Explore a stylish authentication interface featuring smooth transitions between login and registration forms, interactive input fields, and a vibrant gradient background.

**Live Demo:** [User Authentication System](https://diptodeepb.github.io/User-Authentication-System/)

---

## ✨ Features

- Modern login and registration interface
- Smooth animated transitions between forms
- Interactive input fields with floating labels
- Username, email, and password fields
- Remember me checkbox
- Forgot password link
- Social login icons for Google, Facebook, and LinkedIn
- Vibrant gradient background and glass-like form container
- Responsive layout for different screen sizes

---

## 🛠️ Tech Stack

| Technology | Purpose |
| ---------- | ------- |
| HTML5 | Website structure and form elements |
| CSS3 | Styling, layouts, animations, and responsive design |
| JavaScript | Interactive form switching |
| Boxicons | User interface icons |
| Font Awesome | Social media icons |
| Google Fonts | Poppins typography |
